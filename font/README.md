# URAJI（裏字）

裏フェスの書体。どの字にも、字の高さの 0.618 に一本の線（切れ目）が走る。線より上が表、下が裏。

- 使い方・色・組み方のルール：[裏フェス フォント（デザインシステム）](https://claude.ai/artifact/51KpKXTyAqecGQS2kp2hRK)
- 形を動かして決める：[URAJI つまみ](https://claude.ai/artifact/FabYiinMDhuPoC8WHhADeW)（`tool/knobs.html` のもと。公開中のページはまだ v0.3 で、小文字と小文字のつまみはこのリポジトリの `tool/knobs.html` にだけ入っている）
- 光でつくる見せ方の試作：[URAJI 光の字](https://claude.ai/artifact/AJfsz5zmbwquiHFTb3dHfb)（`tool/light.html` と同じもの）

## ファイル

| ファイル | 中身 |
| --- | --- |
| `URAJI-Black.otf` | Figma・Canva・Illustrator・動画編集ソフトに入れる |
| `URAJI-Black.woff2` | ウェブ（アプリ）で読み込む |
| `src/glyphs.js` | 字形の正本（英大文字・英小文字・数字・記号・裏）。全字をつまみ（`DEFAULTS`）から組み立てる |
| `src/kana.js` | 字形の正本（カタカナ） |
| `src/kanji.js` | 字形の正本（祭・新字「うらまつり」） |
| `src/export.js` → `src/build.py` | 字形を演算の木として書き出し、pathops で OTF・WOFF2 にする |
| `tool/` | つまみの道具と光の字のページ。同じ正本を読むので、道具で見た形とフォントの形は一致する（祭と新字は道具に入っていない） |
| `build.sh` | 全部を作り直す |

ここにある `URAJI-Black.otf`・`URAJI-Black.woff2` は、デザインシステム「裏フェス フォント」に置いたものと同じファイル。

## 文字セット（v0.4）

英大文字 A–Z と英小文字 a–z、数字 0–9（等幅）、記号 `. , : ; ! ? - – — ' " ( ) / + = × # ·`、矢印 `→ ← ↑ ↓`、カタカナ全部（小さいかな・濁点・半濁点・ヴ・ヰ ヱ ヷ〜ヺ・踊り字 ヽ ヾ）、`ー ・ 「 」 、 。`、漢字は 裏・祭 と新字（うらまつり、U+E000）。ひらがなは入っていない。

- 小文字は、線から下（裏）にまるごと収まる。x の高さ＝線の下の縁（字の高さ 700 に対して 413）で、小さいかなと同じ決まり。線を越えて表へ出るのは、上へ伸びる画（b d f h k l t）と i・j の点だけ。f と t の横画は線の真下（大文字の中間画と同じ）
- 小文字だけの語（minimum など）には線が見えない。線を見せたい見出しは、大文字か上へ伸びる字を含む語で組む
- `font-feature-settings: "ss01"`（型紙セット）で、閉じた穴が残る B・6・8・裏・パ行・。と小文字の a b d e g o p q にも短い切れ目が入り、全字が一枚の板から切り抜ける
- 「裏」「祭」と続けて打つと合字で新字になる。`"ss02"` で「裏」が全部新字になる（文字データは裏のまま）

## 作り直す

```sh
pip install -r requirements.txt   # fonttools, skia-pathops, brotli（Node も使う）
./build.sh                        # src/glyphs.js の DEFAULTS の値で作る
./build.sh try.json               # つまみの値を試す（例: {"SLIT":0.6,"T":44,"VL":140}）
```

つまみは 線の高さ・線の厚さ・縦画の太さ・横画の太さ・字幅・角の半径・角の張り・字間・小文字の縦画（`VL`）・小文字の横画（`BL`）の10個。小文字の x の高さはつまみではなく線の下の縁から決まるので、線を動かすと小文字の背も一緒に動く。

つまみの道具で「この値で決める」を押した値は、`src/glyphs.js` の `DEFAULTS` に書き写してから `./build.sh` を回す。字ごとに手で直さない。
