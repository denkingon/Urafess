# 画面コンポーネント

> **最終更新日**: 2026-11-16
> **更新者**: AI (Codex)

参加者と主催者の画面を構成する。主催者の本部 HQ は `hq.ts`、左メニューでダッシュボードとルール設定を切り替える。設定のピッカーは `hq-picker.ts`、夜の予定は `night.ts`、参加者の配役希望は `wish.ts` が担当する。ダッシュボードは全体地図、地図上に重ねる6つの人数表示、参加者とチャットのダイアログ、ミッションの要約を一画面に並べる。ミッションは地図の位置設定ボタンの下に、進行操作は地図の右下側に表示する。
